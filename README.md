# 双增益预览的分组 Winograd 卷积与精算接续

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

RGB-M 特征用 HWC。group 指该输出通道读取的输入通道列表。每组 3×3 卷积以零填充为准，核为相关运算的顺序，gain 作用在输入通道，偏置作用在卷积后。参考数值使用 float64 直接相关。预览与编辑要求逐输出值的绝对误差：preview 0.03、edit 0.001。量化变换路径使用设备包声明的中间数有效位数，未达到目标误差可选择等价精算。设备试用典型为 640×360×16 空间，单窗口内部工作区 64 KiB，顺序输入可由调用方重读。同一帧数据与其 gain 版本的 SHA 标识由相机提供。 量化变换域倍率统一在真实路径中计算，核预处理可在同一帧内复用。对典型帧的内部整块并行区，预览路径用于卷积的标量乘法总数不超过该区直接 3×3 相关的 80%，计算跨度包含精算回退和误差核对。边缘像素允许单独走精算。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。rows 事件给出相机初次送达的半开行范围。preview、edit 事件分别给出 gain 版本和半开读区。profiles 各项为设备名、字节上限、低精度有效位数。
