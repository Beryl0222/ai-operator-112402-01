# 双增益实拍的分组卷积与交错感光校准

这里的感光条带与模型包是用于设备联调的合成资料。使用 Node.js 22。运行 `npm ci --offline` 核对依赖锁，`npm run inspect` 查看资料字段，`npm test` 检查资料格式及相互引用。检视脚本只读取元数据。

## 数据格式

小样本和两路传感器典型尺寸见 inputs/captures.json，空间使用 HWC，矩形半开。线性域为 max(0,(raw−black[phase])*gain[phase])。phase=(row%2)*2+col%2。高路 raw 小于本相位 saturation 时始终用高路，否则用低路。已知越界位置补零。输入码为无符号 12 位。第一层输出通道 o 按 o // 4 所在四通道组读取，o 对每个组内通道使用 banks[(o+c)%banks.length] 的 3×3 核，叠加 bias[o%bias.length] 后限到 [0,clip]。第二层取第一层同通道的 3×3 相关并加 detailGain 倍直连输入，叠加后不再次限幅。误差与逐项 float64 参考比较。典型帧取景批次是 rect 内全部通道，预算 workBytes 同时包括两层工作块、校准临时块、缓存及各消费方尚未领的缓冲，调用方源条带、已领取的输出及模型常量除外。对 rect 内普通场景的典型全量预览，标量等效乘法上限是同型直接两层相关与相位校准总量的 83%，每个变换和资格判断中的乘法也计算在内。加法、位移分别记录，不能把浮点乘法改名为位移规避额度。典型采集记录可通过 captures.mjs 取得。 普通区与逆光区的交接请求独立计峰值。第一层和第二层模型包中的零系数保留正常零语义。设备给出实际逐值核验的最大容差，不要求内部使用某个固定快速算法。 预览的设备数据通路最高 11 个有效位，整数拆宽仍按实际宽乘次数记录。相册精算可使用 float64。超预览精度或额度后要先返回可发布普通区，不能把本次取景整体转到相册通道。按位宽将一次超 24 位的实乘折计四次，一次 12–24 位折计两次，设备基线也按同一口径。

## 取数

`inputs/captures.json` 保存标定、规格和调用记录。记录中的范围除明确说明外从零开始，使用半开区间。批量数组按调用记录列出的顺序交付。capture(page, sensor, variant) 读取单路相机条带。sensor 1 为高增益，0 为低增益，variant 默认为 0。
